Für Windows herunterladen

Beim ersten Start warnt Windows SmartScreen, weil der Installer nicht signiert ist: „Weitere Informationen“ anklicken, dann „Trotzdem ausführen“. Lichtkammer installiert sich ohne Admin-Rechte und legt eine Verknüpfung auf den Desktop.
